# Preprocessing Checklist

- [ ] Record official source URL, publisher, retrieval date, licence/terms, and dataset period.
- [ ] Preserve an unchanged raw copy.
- [ ] Inspect row/column counts and data types.
- [ ] Standardize column names and trim text.
- [ ] Measure missingness; document handling rules.
- [ ] Check exact duplicates and business-key duplicates separately.
- [ ] Parse dates and numeric values with explicit rules.
- [ ] Investigate outliers; do not remove them automatically.
- [ ] Apply scaling/encoding only when required by the analysis.
- [ ] Validate ranges, categories, and related-field consistency.
- [ ] Save a data dictionary and transformation log.
- [ ] Compare quality metrics before and after processing.
- [ ] Confirm no restricted data or credentials are committed.
